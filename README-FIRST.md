# Explore India – Travel Guide

## Open locally
Open `index.html` in a browser. No server or installation needed. Internet connection is required to load third-party Unsplash photos.

## Publish with GitHub Pages
1. Create a PUBLIC GitHub repository called `explore-india`.
2. Upload the CONTENTS of this folder to the root of the repository (not the ZIP itself).
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Visit https://YOUR-USERNAME.github.io/explore-india/ after deployment.

## VERY IMPORTANT: Set your real website URL before publishing/SEO analysis
Search-and-replace `https://YOUR-USERNAME.github.io/explore-india` in all HTML files, `sitemap.xml` and `robots.txt` with the EXACT public URL of your published website, without the ending slash. Otherwise canonical, Open Graph, schema and sitemap URLs will still contain placeholder text. If your repository is not `explore-india`, change the path too.

## Features
- 8 standalone destination pages, 3 standalone travel guides
- Search, category filtering, alphabetical sorting, saved places
- Editable itinerary with local-storage persistence and TXT export
- Budget estimator with clearly illustrative assumptions
- Packing checklist with persistence and progress bar
- FAQ, about, privacy, 404, responsive mobile menu
- Meta title/description, one H1/page, semantic HTML, alt text, JSON-LD, sitemap, robots.txt, canonical, Open Graph

## Analytics and SEO audit
- Search Console: https://search.google.com/search-console/ ; verify ownership and submit sitemap.xml.
- Google Analytics: https://analytics.google.com/ ; create your property and insert YOUR OWN Google tag code in each HTML file just before `</head>`. Do not invent data.
- Lighthouse: Chrome Developer Tools → Lighthouse, test mobile and desktop.
- Keep screenshots of published website, search/filter features, SEO audit, analytics and Search Console.
- Newly published websites may have no traffic or indexing yet; report this honestly.

## Limitations
Photos load from Unsplash over an internet connection and some photos may be illustrative rather than depicting exact named destinations. Replace with your own appropriately licensed destination-specific images before formal publishing if accurate location photography is essential. Budget figures are NOT live travel prices. The informational content is simplified and should be verified before travel. Browser localStorage is not synced between devices. No bookings, login, live prices or real analytics are included by default.

## Privacy note
If you add Google Analytics or other trackers, update privacy.html to state what data is collected and check applicable consent requirements.
